# Pisper 中文科技产品宣传片创意简报

## 交付目标

- **成片时长：60 秒**，中文，建议主版 1920 × 1080、30 fps。
- **核心创意：一次灵感，多路推进。** 从对话与语音表达灵感，用连续流式回复连接到并行会话、分支探索与可视化工作流，最后回到跨桌面、终端、移动端的多 Agent 工作空间。
- **核心动态功能占 20 秒：** 对话模式 6 秒、语音输入 7 秒、SSE 流式渲染与平滑滚动 7 秒；安排在 00:06–00:26，形成连续的体验主线。
- **表达原则：真实功能画面为主，中文极简标题辅助理解。** 使用主 Agent 拍摄的真实 UI，不虚构操作反馈，不加入性能数字或效果保证。
- **情绪节奏：** 安静聚焦 → 自然表达 → 回复展开 → 多路推进 → 品牌收束。

## 视觉与声音

深色背景，蓝绿作为少量强调色；优先保留真实 UI 配色。外层包装采用细线、柔和光晕与克制的窗口阴影，避免满屏粒子与高亮 HUD 遮挡操作。中文使用清晰无衬线字体，标题约 56–72 px，说明约 30–36 px；文字距画面边缘至少 96 px，并避开关键控件。

每个主要功能至少留出约 2 秒稳定阅读时间。真实 UI 可裁切、平移、适度放大，但不合成不存在的按钮或状态。对话、语音、流式渲染三个核心段落采用真实动态录屏；流式渲染段保留连续原速镜头，后期不补字、不制作模拟滚动、不用速度调整掩盖卡顿。其余会话录屏可组成分屏包装，不将剪辑拼接描述为自动协作能力。

建议无旁白主版，配克制的电子氛围音乐，约 100 BPM；使用具备授权的音乐素材。对话段加入轻节拍，语音段压低配乐以听清示范句，工作流段形成轻微峰值，最后两秒收尾。点击音只对应真实操作。如需旁白，使用文末可选口播，语音演示时不叠加旁白。

## 素材交接与注意项

1. **优先拍核心 20 秒。** 主 Agent 先采集对话模式、语音输入、SSE 流式渲染与平滑滚动，再采集其他功能。每条录屏额外保留前后各 2 秒；流式回复建议多录若干秒，以选择包含实际滚动的连续 7 秒。
2. 三个核心段落必须使用真实动态素材。对话模式应可识别，语音应包含真实录音与转写结果，流式段应同时拍到增量文字和滚动。截图或标题卡不能视为完成这些动态功能展示；素材缺失时明确交接补拍项，不制作假 UI。
3. 为语音示范准备短句，按真实识别结果决定可用镜头；字幕不能代替识别结果。语音输入不延伸宣传为语音通话、语音回复或自动提交。
4. SSE 是本次委托指定的技术机制，镜头展示用户看到的逐步渲染与平滑滚动。仅凭画面不能核验传输协议；由主 Agent 确认拍摄场景确实走 SSE，字幕不宣称延迟、帧率或所有环境下的流畅保证。
5. 使用演示会话，隐藏 API Key、个人路径、账户信息、私密项目内容及通知。任务名称只表达用途，不承诺自动完成或成功率。
6. 文案仅使用委托方给定事实及新增重点：跨桌面、终端、移动端的多 Agent 工作空间；并行会话分屏；会话树/分支；可视化工作流；工具/MCP/记忆；对话模式；语音输入；SSE 渲染与平滑滚动。不加入性能数据、自动同步、无人值守完成等主张。
7. 其他功能素材不足时，可用真实截图配轻微镜头移动；某端素材缺失可用准确的平台名称文字卡，但应向主 Agent 标明素材缺口，不声称已演示该端操作。
8. 尾卡地址采用委托方确认的官网 `https://pisper.cc`。
9. 输出前逐屏检查中文字体、UI 可读性与地址完整性；最后 6 秒须保留。对话、语音和流式段不标注三端通用的相同行为，拍摄平台与实际效果由主 Agent 核验。
