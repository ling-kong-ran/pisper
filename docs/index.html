界面

Agent 的每一步，都摆在台面上。

分屏、追忆、标签、终端 —— 没有黑盒，没有「正在运行中」的玄学等待。

为什么选 Pisper

每条分支都走完，再决定用哪条。

  1. 01

    对话开分支

    在任意已完成 Turn 衍生新会话，继承上下文，源会话一字不改 —— 像 Git，但给 Agent 用。

  2. 02

    并行不排队

    多会话同屏推进，每个 Agent 各自为战，进度肉眼可见。

  3. 03

    工具冷热分明

    核心工具常驻上下文；插件、MCP 与技能经网关按需激活、用完即退，再丰富也不挤占。

  4. 04

    Pi 内核，深度优化

    在 Pi 运行时之上优化工具按需加载、定义稳定排序与提示词形态诊断：上下文更轻，长会话更快、更省。

  5. 05

    能力不设限

    插件自己写、MCP 随手接、技能按需装 —— 想要就说，说完就有。

  6. 06

    多端不脱节

    桌面、TUI 与手机共享同一 Runtime，Git / SVN 工作区都在。

数据安全

默认不出机，出门要审批。

Pisper 没有「我们的云」。数据躺在本机目录里，只有你点名的 Provider、MCP、 搜索和渠道，才会收到完成请求所需的那部分。

LOCAL DATA ROOT

~/.pisper/agent 可通过 PISPER_AGENT_DIR 更改位置 会话、记忆、工作流、日程、用量与连接配置，默认都保存在这里。
  1. 01

    连接由你开启

    远程访问默认关闭；开启后，只有完成配对的设备可以连接，每台设备都能单独移除。

  2. 02

    敏感先脱敏

    常见密钥、令牌与连接信息，在保存和展示前自动隐藏。

  3. 03

    权限有边界

    为 Agent 选择只读、单次审批或完全访问，关键操作始终由你决定。

  4. 04

    记忆需确认

    自动推断的记忆先进待确认区，你点头之前不参与召回；候选、单条、整个会话都可拒绝或删除。

诚实边界

自动脱敏无法识别所有隐私内容。发送 Prompt、文件或工具结果前，请确认其中没有不该分享的信息。

同一内核，两个入口

离开桌面，上下文不走。

Ratatui TUI 直连同一 Runtime：用量、思考状态、工具活动、计划与 Git/SVN 工作区能力全都在。 Node.js 20+ 一条命令：

npm i -g pisper

装完即用：/provider 选择 Provider 并配置 API Key； pisper web 直接打开 Web 前端与本机配置页。

移动端 · MOBILE

Pisper，随身带走。

手机上可以直接运行同源 Node/Pisper Runtime，也可以连接桌面 Pisper。 在家优先走局域网，离家自动切换 P2P；模式与会话都由手机记住。

  1. 01

    两种模式，平等选择

    首次打开即可选择本机运行或连接桌面，不强制扫码，也不把本机模式藏进设置。

  2. 02

    同一套本机 Runtime

    标准 Agent、Provider、会话、HTTP/SSE 与 React 界面都在手机运行，并按设备能力自动调整入口。

  3. 03

    桌面连接自动选路

    扫码配对后优先 LAN，离开局域网自动回退 Iroh P2P，网络变化时无需重新配对。

  4. 04

    手机导航，能力透明

    底部主导航一键切页；普通设备按 Runtime 清单降级，rooted Android 自动使用能力更完整的载体。
