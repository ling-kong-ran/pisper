能力矩阵

想到，就有人去做。

每一项能力都不是演示图 —— 点开卡片，直达对应的教程章节。

01

并行会话

标签一拖，四面分屏。多个 Agent 同屏推进 —— 没有黑盒，没有玄学等待。

→ 02

追忆分支

在任意已完成 Turn 衍生新会话，继承上下文，源会话一字不改 —— 像 Git，但给 Agent 用。

→ 03

对话生成图片视频

要图得图，要片得片。生成能力就在对话里，产物自动归档进资产库。

→ 04

团队模式

把一个目标交给一支 Agent 小队：分工、推进、汇总，Token 预算握在你手里。

→ 05

手机上的真 Agent

内置 Node Runtime 本机执行：Agent、工具、会话都在手机上 —— 手机不是遥控器。

→ 06

可视化工作流

Prompt、文件、MCP 与通知连成图，重复的事交给流程去跑。

→ 07

星忆 · 项目记忆

事实、偏好与决策被记住并可检索；自动推断的记忆，先过你这一关。

→ 08

定时任务与通知

到点自跑，结果经渠道推到 IM。你不盯屏，也不错过。

→ 09

插件 · MCP · 技能

插件自己写、MCP 随手接、技能按需装 —— 想要就说，说完就有。

→ 10

数据安全

没有「我们的云」。数据躺在本机 ~/.pisper/agent，出门要审批。

→ 11

组件按需更新

Desktop、TUI、Runtime 独立版本、独立签名、独立更新，失败自动回退到内置版本。

→
