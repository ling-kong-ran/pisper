# 会话组件画布

- 状态：已采纳
- 日期：2026-09-25
- 影响范围：React Web、桌面 WebView、Android/iOS 共用前端；不改变 Runtime 或 TUI 协议。

## 背景与决定

原有自定义 UI 在独立沙箱中加载 HTML，不能编排会话页面。第一版布局模板只提供位置、宽度、字体等固定选项，无法满足自由组合组件与自定义样式的需求。将其扩展为版本 2 组件树：横排、竖排、网格容器可嵌套，内置会话组件与文本、分隔线、留白可置入容器、换序和编辑样式。桌面与手机各持有独立画布。

每个节点保存 CSS 声明，通过无 DOM 的属性和值校验后映射到该节点的内联样式。支持颜色、字体、尺寸、间距、边框、阴影、渐变和 flex/grid 布局。模板不执行脚本、不加载外部资源、不注入全局选择器。独立 HTML 组件仍通过原沙箱加载，两类功能的权限边界保持独立。

消息与输入框必须各有一个；其他功能组件最多一个；装饰组件与容器可重复。模板校验限制节点数、嵌套深度与文本大小。编辑器提供拖放、键盘/触屏等价移动操作、样式检查、撤销/重做、预览、应用、命名保存和 JSON 导入导出。预览使用示例内容，不请求会话 API。

## 文件与状态所有权

本次不搬迁旧聊天、组件服务或沙箱文件。新增与修改的职责映射：

- `src/features/chat/layout/chat-canvas.ts`：组件树契约、边界校验与不可变树操作；`chat-canvas-style.ts`：节点 CSS 声明校验。
- 同域 `chat-layout.ts` / `chat-layout-store.ts`：版本化模板、旧数据迁移、预设与持久化；`public.ts` 是应用壳的轻量接口，`editor.ts` 是编辑器的懒加载入口。
- 同域 `ChatCanvasLayout.tsx`：递归容器与功能槽位渲染；实际功能块继续由 `FocusSession` 提供。稳定的 portal 宿主随布局移动，避免跨容器调整导致输入框与消息状态重建。
- 同域 `ChatLayoutSwitcher.tsx`：通过应用壳注入通用 `PageHeader.actionsSlot`，在会话页选择内置/命名模板；`switcher.ts` 独立懒加载，不由基础组件反向依赖聊天领域。
- 同域 `ChatLayoutTransfer.tsx` / `ChatLayoutLibrary.tsx`：复用导入导出与命名模板管理。导出只包含模板契约，文件读取带取消代际，重命名保留 ID，导入同名自动生成新名称。
- 同域编辑器与检查器：持有未应用草稿、选择、拖放与撤销历史。Zustand 只保存已应用模板及命名模板；预览不写入会话状态。
- `src/app/ChatAppearancePage.tsx`：通过配置页的渲染插槽组合原有外观设置、布局编辑器和独立组件，统一放在「设置 → 界面设置」的三个标签页。编辑器及独立组件仅选中时加载；`/components` 兼容重定向到 `/config/interface?view=layout`，主导航不再保留独立入口。
- `src/app/ChatLayoutNavigation.tsx`：懒加载桥接，将导航配置交给通用 `AppSidebar` 参数；通用组件不依赖聊天领域。
- `FocusSession` / `ChatDock`：复用现有发送、草稿、附件、流式消息、模型选择与工具操作。上下文组件复用原文件审批和计划规则，确认回调由 `ChatPage` 注入，不复制业务状态。
- `ChatPage`：当画布已有上下文组件时关闭外层重复面板；未嵌入时保留既有侧栏、移动抽屉和完成后自动打开行为。

导航折叠仍以 `ui-store` 为权威；模板在显式应用时设置一次。上下文宽度仍由 `session-context-store` 管理拖动和重启恢复。模板的初始宽度不持续覆盖用户拖动。

## 兼容、验证与回滚

模板输出版本为 2；版本 1 的桌面/手机配置自动迁移为组件树，旧输入框位置映射到节点顺序。存储容器保留版本 1，内部模板经统一解析器迁移。未知版本、非法节点、循环移动、重复功能组件和不安全 CSS 被拒绝。损坏存储回退默认布局，写入失败保留当前内存状态并提示未持久化。

布局保存在当前浏览器/WebView，可用导入导出跨设备传递，没有新增服务端权威副本。会话页切换修改本设备全局偏好；库中的模板与已应用快照分别持有内容，重命名仅同步名称和内容仍匹配的活动快照，不重新应用布局或重置上下文宽度。移动端默认采用独立竖排画布；自定义手机画布由用户自行编辑，桌面导航宽度不会套到手机上。

验证覆盖旧模板/存储迁移、树操作、CSS 边界、渲染、草稿保持、导入导出、移动视口、国际化、懒加载和生产构建。Web 视口检查不能替代 Android/iOS 原生构建与真机验收。

前一版已将消息气泡的旧全局样式迁入 `ChatMessage`；默认宽度的源码守卫使用带默认值的 CSS 变量并配合范围测试。新增画布不取消消息虚拟化、流式状态或文件确认保护。旧组件路由改为兼容重定向后，路由守卫改验重定向目标，并继续检查实际页面动态加载以及编辑器、独立组件的动态导入。

回滚时恢复此组件画布变更前的前端和版本 1 模板解析器；版本 2 存储会按不支持的数据回退默认值。用户可先导出模板作备份。独立组件目录和会话数据无需迁移或删除。

## 复查条件

需要跨设备同步、第三方功能组件、任意 HTML 替换消息渲染器、外部样式资源或新模板版本时，重新评估权限、状态所有权、迁移和可访问性。
