# 决策模型的协议与审批边界

- 状态：已采纳
- 日期：2026-09-22
- 范围：决策 Runtime、设置页与共用 HTTP 契约。桌面、Android、iOS 使用相同实现，无新增原生命令、资源或权限；TUI 保留旧 JSON 字段。

## 问题与移动映射

过去 DecisionService 直接依赖 Jev 客户端，供应商只是同一协议的端点预设；业务读取 noul，任意模型复用同一审批阈值。SDK 接入只替换了 HTTP 重试，没有完成模型抽象。

| 原职责 | 新所有者 |
| --- | --- |
| decision-remote-client 输入校验 | decision-input.mjs：应用入口限制和 boolean/choice/score 领域问题 |
| Jev 问题、上下文限制、SDK 调用 | decision-jev-adapter.mjs，调用已有 transport / response 边界 |
| 旧 noul 名称与内部结果 | decision-contract.mjs：v1 兼容转换和所有适配器共用的结果校验 |
| 固定供应商选择 | decision-registry.mjs：供应商 → 协议 → 型号能力/审批策略 |
| 默认接线 | decision-backends.mjs：注册 Jev 实现与现有型号的兼容审批策略 |
| 前后端重复默认值 | shared/decision-provider-catalog.mjs 及类型声明，纯元数据 |
| 旧客户端导出 | decision-remote-client.mjs 保留兼容门面，业务服务不再使用它 |

## 契约、状态和扩展

DecisionService 继续拥有配置、原子持久化、停止信号、在途任务和审批规则。注册表无长期副作用，适配器只接收已解析端点、认证、型号、领域请求和取消上下文；不得接收整个 Runtime。SDK 只在 Jev 适配链中按需加载。注册表给出整个调用的 120 秒总时限信号；适配器负责网络资源、重试和收到取消后的收尾，服务停止取消并等待它们结束。第三方适配器必须消费信号，不能通过只抢先返回而遗留请求来伪装取消。

新协议实现一个 DecisionAdapter，返回 unknown，经注册表统一验证问题 ID、类型、选项、有限概率和用量。纯布尔结论可以没有概率；不得把 true/false 伪装成 1/0 或把任意 confidence 当成概率。v1 noul 需要真实概率，缺少该能力返回 unsupported_capability。测试连接选择模型支持的问题类型，不要求所有模型都支持是非判断。

供应商绑定协议和默认地址；同协议新型号可以只改 modelId，继承协议基础能力。可登记型号的能力子集，不允许型号声称协议不具备的能力。新协议只需注册适配器及供应商，业务审批层不增加供应商分支。新增正式供应商的用户入口仍需同域表单文案及双语覆盖；当前没有交付第二家真实协议实现。

## 阈值、迁移和兼容

自动审批必须同时满足概率能力、精确型号的审批策略、当前端点的阈值绑定。默认 Jev 型号保留 legacy-jev-v1 行为；这属于既有兼容策略，不是跨模型校准证据。新型号不按名称前缀自动继承；策略由应用代码登记，不能通过模型响应或用户配置声明自己可信。

v1 配置增量保存 approvalBinding（供应商、型号、端点、策略版本），不改变旧字段含义。旧文件无该字段时，根据文件中原型号生成兼容绑定；保存其他改动时一并写回。切换型号或端点保留原绑定，审批回退人工；用户为当前模型重新保存阈值后才更新绑定。未知或无概率的模型即使保存阈值也不能启用自动批准。配置写入串行并递增修订号；推理期间配置改变后，即使随后切回原模型，旧结果也不能批准新配置下的操作。

HTTP status/config 增加可选 approval.status，旧客户端忽略新增字段；新客户端兼容旧服务未返回状态的情况。decide/test 的现有字段与 noul 名称保持，新增错误码 unsupported_provider / unsupported_capability。设置页给出模型未登记策略或阈值待确认的中性提示。

不建立动态插件加载框架，也不自动探测远端模型：当前扩展需求通过静态注册和窄接口即可满足。

## 验证与回滚

在既有 runtime/tests 入口增加第二种模拟协议，覆盖普通判断、旧 API、审批、能力拒绝、非法响应、取消/停止、旧配置读取、模型切换与在途配置变更。模拟协议必须不使用 Jev SDK 或 noul 请求形状。同步运行类型、全量测试、i18n、前端构建、TUI 检查和 SEA 闭包验证。

三端前端入口均为 DecisionsPage/DelegationCard，原生命令、依赖资源打包和权限不变；生命周期为共用 Runtime 的取消/停止。这里只能报告实际完成的本机源码/构建测试，不能等同 Windows 或移动端设备验收。

回滚需成组恢复契约、注册表、服务、共享元数据和客户端。新增绑定字段不含密钥；旧版会忽略它，但也会丢失模型切换保护，因此回滚前应禁用自动审批，不能宣称旧版仍保留这些保证。兼容门面待所有旧导入迁完且相关测试迁移后再删除，不在本次删除公共字段。

### 设置页精简

页面仅保留模型连接和使用方式，移除 Jev 专属介绍及常驻大段说明；供应商选项和合法值校验来自共享目录，实际模型 ID 仍由配置决定。缺密钥、审批不可用或阈值待确认时显示简短提示。连接失败使用中性色并折叠详情；草稿未保存时不允许测试旧配置。保存使用方式不会覆盖连接表单的未保存草稿。该轮仅修改共用 React 界面与文案，不改变模型协议、原生命令或审批策略。
