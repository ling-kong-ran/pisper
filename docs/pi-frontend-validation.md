### 实际浏览器交互覆盖

- 用隔离 Provider 配置 API 注册本地 OpenAI-compatible SSE fixture。模型与智力在一个面板中修改并经刷新保留。
- 不支持推理及仅固定关闭档位的模型不能调整智力；切回支持的模型后恢复；生成期间模型和智力均只读。release 的自定义档位总会保留 `off`，因此“只选 high”不等于固定档位。
- Plan/Goal 切换、刷新持久化；审批后写入、自动审批、完全访问的真实状态切换；完全访问可取消、需显式确认，测试最后恢复审批后写入。
- 默认权限、执行模式、模型与智力三个控件常驻；可收纳和恢复默认，偏好经刷新保留。会话菜单没有上下左右分屏或不可关闭的窗格入口。
- 中文 IME 确认 Enter 不发送；Shift+Enter 换行；附件、资源、生成图片、命令和手动压缩入口可达。
- 真实聊天 HTTP/SSE 的部分回复、完整回复、历史落盘与刷新恢复；切换活动会话不取消后台流；排队消息可撤回到草稿；停止会关闭上游连接。
- 会话草稿隔离、通过历史页重命名和确认删除、API 验证删除结果；顶部侧栏按钮单次折叠/再次展开；原有布局 JSON 导出、导入并切换后不丢草稿。
- 右侧文件改动、计划、网页预览选项卡可键盘切换、关闭重开。
- 320、390、768、1440 px 下三个主控件可见，没有文档或输入栏水平裁切；真实主题按钮切换深色并刷新保持，检查浅色/深色截图。

## 测试隔离与未验证范围

- 测试使用系统临时目录 `pisper-zcode-ui-*`、随机回环端口、临时工作区和显式假密钥；不读取真实 Provider 凭据或用户会话，不消耗付费模型额度。
- Provider 网络发现和 GitHub 更新检查在浏览器中使用标明的固定响应，不依赖互联网。其余测试 API 出错会直接失败；真实 GitHub 更新请求单独检查，不能用此 smoke 结果证明在线更新正常。
- 测试结束先关闭浏览器、fixture 和 Runtime，再删除本次临时代理数据/工作区；报告、失败信息和截图留在同一临时目录供检查。可手动删除报告目录，不提交测试产物。
- 未进行真实模型、MCP/插件安装、第三方通道、远程设备、麦克风/扬声器、真实图片生成、Team 多代理调用、系统终端/桌宠及自动更新安装验收；能力入口与后端实现保留，不以本地 fixture 代替这些验证。
- 未构建 Tauri 安装包、Rust TUI、Android 或 iOS 原生应用，也未覆盖实体设备键盘和 WebView 行为。Safari 解析审计不等于 iOS 设备验收。

## 真实在线检查

推送前端提交后，真实更新检查曾返回 GitHub HTTP 404。独立查询确认仓库 API 返回 200、默认分支为 `release`，而 `/branches/main` 返回 404；不是 UI 错误或未推送 HEAD 导致。已修正共用默认分支及前端缺省标签，并保留超时、并发复用、ETag/离线回退与禁止 Web 自动下载的现有行为。修正后的真实 GitHub 检查已返回 `state: current`、`branch: release`、`behindBy: 0`、`canDownload: false`。源码更新检查对比 release 基线，不是独立前端自动升级器。
