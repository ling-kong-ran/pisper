## 已实现的范围

- 小发送按钮（32px）；紧凑模型/智力弹层；生成中可预选下一轮模型与思考强度，不修改当前运行。
- 侧栏展示工作流、资产，隐藏自动化/插件/重复终端入口；终端保留在右上角。
- P 头像和 Pisper 名字为整个可点击菜单，包含 Provider、外观。
- 字体基准 14px，只支持 13.5 / 14 / 14.5px；层级比例固定，不缩放间距与图标。
- Provider 左右工作台和独立模型编辑器，参照 ZCode 布局并保留实际后端能力。
- 自动读取支持的本地 Claude Code/Codex 文件配置，幂等导入，不覆盖既有凭据；浏览器不收到密钥。
- 同一连接配置模型能力与思考等级，支持仅生图模型，不进入聊天模型选择列表；手动模型不被目录刷新删除。
- 运行会话旋转状态；新建工作流保存成功返回、失败保留、运行前静默保存仍留编辑页。
- 新建页 P 背景、输入框下的推荐任务、单列加号菜单。
- 追忆会话树：标记、全局标记索引、搜索、从历史继续、另开子会话、返回父会话、删除标记和重载持久化。
- 星忆知识页面：新建空间/节点、编辑、搜索、审批/忽略、删除和重载持久化；旧搜索响应不覆盖新结果。星忆知识库与追忆会话树是两项不同的功能。

## 配置写入边界

配置状态仍由 ProviderPreferences 持有，没有移动文件或新增跨 Feature 依赖。
Facade 的连接、密钥、模型、启停、新建/删除、导入及目录刷新共享实例写队列；
自动导入与刷新保留请求去重，嵌套调用可重入，失败不阻塞后续写入，脱离原操作的异步任务不能保留锁。
公共 HTTP 契约未修改，Web/TUI 仍使用现有入口。
此队列限于同一 Runtime 实例，不宣称多个操作系统进程之间具有配置事务。
